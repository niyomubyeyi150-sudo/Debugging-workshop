EXERCISE 01

Know your bugs

Understand the problem before changing the code.

Syntax

Syntax error

The code cannot be parsed correctly.

console.log("Hello"

Fix: add the missing closing parenthesis.

Runtime

Runtime error

The code crashes while it is running.

user.name

Problem: user may be undefined.

Logic

Logic error

The code runs but produces the wrong answer.

"10" + 20

Result: "1020", not 30.

Your debugging process

  1. Reproduce the problem.
  2. Read the error message and line number.
  3. Form a hypothesis about the cause.
  4. Test it with a breakpoint or console output.
  5. Fix one problem at a time and test again.
  6. Explain the cause and commit your fix.
